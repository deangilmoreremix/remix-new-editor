# Stage 2 report: keyframes, motion graphics, Lottie (CineGen, `#/timeline`)

Scope: `src/cinegen/` plus the shared composition files it feeds (`TimelineComposition.jsx`, `timelineToComposition.js`, `overlayRender.js`, vendored caption renderer).
No new dependency. Nothing from Stage 4 (audio, proxyGenerator) or Stage 6 (transitions, glTransitionRenderer) was edited.

## What was found first (not reimplemented)
CineGen already had three key stores: `Clip.keyframes` (opacity / volume, linear), `Clip.transform.keys` (x, y, scale, rotation, linear) and `ClipFx.keys` (OpenChatCut keys per effect slider, with bezier easing but no UI).
Crop was static (`transform.crop`), masks are GL effects (`fx-rect-mask`, `fx-circle-mask`) whose sliders are effect parameters, Lottie played only through sticker overlays (lottie-web in the preview, `@remotion/lottie` in the export).

## Limitations
- Keys are clip-relative seconds. Trimming the head of a clip does not shift them (same as the older keyframes). Changing a clip's speed does not rescale them.
- A cut inside an eased segment re-bases the first half's end on the sampled value and the second half starts as linear to the next key (exact only for linear segments or cuts on a key).
- A transition-extended layer in the export starts its clock earlier than the preview's clip clock (existing behaviour of the older transform keys too).
- Effect parameters are addressed by the effect's index in `Clip.fx`; reordering / removing an effect with animated parameters shifts them.
- The dopesheet shows `Clip.anim` plus the folded older transform / opacity keys; older per-effect keys (`ClipFx.keys`) and volume keys still work but are not listed in the dopesheet.
- Timeline clip diamonds (`keyframe-track`) still show only the older opacity / volume keys.
- Modifiers apply to the picture (transform, opacity), not to audio. The Electron native visual path does not apply transform / modifiers (the web path is the product), as before for transforms.
- No pen-path mask animation (no such masks exist). Per-line text animation is not wired. Overlay (`SmartText`) per-character animation was not attempted. Lottie edits cover sticker Lotties; the generated lower-third / CTA Lotties already had their own fields. Gradient colours, nested precomp text and dotLottie archives are not edited.
- Whole-clip Lottie speed changes the playback rate only; no layer / property editing beyond colour, text and speed.
