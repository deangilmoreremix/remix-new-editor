## 📝 USAGE

### AI Video Generation Mode:
1. Navigate to `/personalize`
2. Select "AI Video Generation" mode
3. Import contacts via CSV
4. Write script with tokens (e.g., `{{firstName}}`)
5. Select AI avatar
6. Choose voice style
7. Generate videos

### Overlay Personalization Mode:
1. Navigate to `/personalize`
2. Select "Overlay Personalization" mode
3. Upload base video
4. Import contacts
5. Configure tokens
6. Generate personalized videos
