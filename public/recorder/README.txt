SmartVid web recorder
=====================
This folder is a build of the Screenity screen recorder (https://github.com/alyssaxuu/screenity),
licensed under the GNU GPLv3 (see LICENSE). It is built from the SmartVid fork's `claude/smartvid-web`
branch (https://github.com/deangilmoreremix/screenity), which runs Screenity's UI, recorder and
editor code in a web page using an emulation of the Chrome extension APIs (src/pages/Web in that repo).
Complete corresponding source: the repository and branch above. Rebuild with `npm run build:web`
there and copy build-web/ into this folder.
