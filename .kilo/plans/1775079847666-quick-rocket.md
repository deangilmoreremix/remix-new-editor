# Final Plan: Add VideoRemix Features to Higgsfield Timeline Editor

## Critical Context

- **Source repo** (`/workspaces/remix-new-editor`): Next.js + React + MobX + Material-UI — a full video editor with timeline, canvas, layers, transitions, lead gen forms, connect templates
- **Target repo** (`Open-Higgsfield-AI`): Vite + Vanilla JS + Tailwind CSS v4 — already has a `TimelineEditorPage.js` with tracks, clips, playhead, AI commands, generation panel, CineGen tools
- **Target pattern**: Functions return `document.createElement()`, use `innerHTML` for static markup, Tailwind classes for styling, `localStorage` for persistence, `CustomEvent` for cross-component communication

## KEY FINDING: Higgsfield Already Has a Timeline Editor

The `TimelineEditorPage.js` already has:
- **Tracks**: video, audio, text, b-roll tracks with clips
- **Playback**: play/pause/stop, time display, progress bar, playhead
- **Editing tools**: Select, Blade, Ripple, Roll, Slip, Slide, Zoom, Hand (8 tools)
- **AI commands**: detect scenes, split, transitions, subtitles, B-roll, speed, stabilize
- **Generation panel**: text-to-video, image-to-video, retake, extend, b-roll
- **Floating panels**: Media library, Properties, AI chat, Music generation, Audio sync, Fill gap, Elements
- **State**: `timelineState` with tracks, clips, subtitles, scenes, media library, generation state

### How Each Feature Integrates

#### Lead Generation Forms
- New `'form'` track type in `timelineState.tracks`
- When user clicks "📧 Form" in toolbar or types "add form" in AI chat, a new form clip is added to the form track
- Clicking a form clip opens the **Form Settings Panel** (floating panel on right side)
- Form Settings Panel has 3 tabs: Styles (colors, fonts, animations), Fields (add/remove/reorder fields), Integrations (webhooks, email)
- Form renders as an overlay on the video preview canvas using the popcorn form plugin's DOM creation logic
- Form submission sends data to configured webhook URLs (user provides these)

#### Retarget/Opt-in Forms
- Same as lead gen forms but with additional popup overlay behavior
- Has popup header text, fill-out text, click text, description
- Multiple webhook support (webhook, webhook2, webhook3)
- Arrow hint overlay for user guidance

#### CTA Buttons
- New `'cta'` track type
- Renders as a styled button overlay on canvas
- Configurable: text, color, border radius, link URL, animation

#### Lottie Animations
- New `'lottie'` track type
- User can upload JSON animation or pick from built-in library
- Renders using `lottie-web` on the canvas
- Configurable: size, position, loop, speed

#### Google Maps
- New `'map'` track type
- Renders embedded Google Map on canvas
- Configurable: location, zoom, map type

#### Social Embeds
- New `'social'` track type
- Renders Facebook Like/Comments/Page embeds
- Configurable: social type, URL

#### Text Mask
- New `'mask'` track type
- Renders see-through text effect
- Configurable: text, font, size, mask image

#### Connect Template Gallery
- New floating panel accessible via "📋 Templates" button
- Shows grid of pre-built form templates
- Click a template → imports its configuration into the current form clip
- Templates stored as static JSON (no server needed)

#### Form Settings Panel (Styles Tab)
- Background color picker
- Font family dropdown
- Font size slider
- Button text input
- Button color picker
- Button border radius slider
- Caption input
- Caption size slider
- Caption alignment radio
- Animation dropdown (21 transition types)
- Inner container width/height/opacity sliders
- Background image URL input
- Brand logo URL input
- Privacy disclaimer text area
- Skip button toggle

#### Form Settings Panel (Fields Tab)
- List of form fields (email, singleline, multiline, number, date)
- Add field button (max 5)
- Drag to reorder fields
- Edit field label
- Delete field
- Field type selector

#### Form Settings Panel (Integrations Tab)
- Webhook URL input + enable toggle
- Secondary webhook URL inputs (up to 3)
- Email notification toggle + email address input
- Facebook Pixel ID input
- Download leads button (exports CSV from localStorage)

#### Transitions Between Clips
- When two clips are adjacent on the same track, a transition button appears between them
- Clicking opens a transition picker: Fade, Dissolve, Wipe Left, Wipe Right, Zoom In, Blur
- Selected transition is stored in clip's `transitions` property
- Transition renders during playback on the canvas

#### Undo/Redo System
- Before each edit, snapshot the current `timelineState`
- Store snapshots in an undo stack (max 50)
- Ctrl+Z pops from undo stack, pushes to redo stack
- Ctrl+Y pops from redo stack, pushes to undo stack

```javascript
// src/lib/stores/createStore.js
export function createStore(initialState) {
  const listeners = new Set();
  const state = structuredClone(initialState);
  return {
    state,
    subscribe(fn) { listeners.add(fn); return () => listeners.delete(fn); },
    update(props) { Object.assign(state, props); listeners.forEach(fn => fn(state)); }
  };
}
```

Matches the Higgsfield pattern exactly — same hero section, same Tailwind styling, same color scheme:

```javascript
export function VideoEditorStudio() {
  const container = document.createElement('div');

  // Hero section (matches Higgsfield style)
  const hero = document.createElement('div');

  hero.innerHTML = `
    <h1 class="text-2xl sm:text-4xl font-black text-white tracking-widest uppercase mb-2">
      Video Editor
    </h1>
    <p class="text-secondary text-sm">Create interactive videos with forms, overlays, and animations</p>
  `;

  // Editor layout: Canvas (center) + Toolbar (top) + Timeline (bottom)
  const editorLayout = document.createElement('div');
  editorLayout.className = 'flex-1 flex flex-col w-full max-w-7xl mx-auto px-4 pb-4';

  const toolbar = Toolbar({ onAddElement: handleAddElement });
  const canvas = Canvas({ width: 1920, height: 1080 });
  const timeline = Timeline({ onTimeChange: handleTimeChange });

  editorLayout.appendChild(toolbar);
  editorLayout.appendChild(canvas.container);
  editorLayout.appendChild(timeline.container);

  container.appendChild(hero);
  container.appendChild(editorLayout);

  return container;
}
```

### Canvas Component

Renders a video preview area where elements (text, images, forms) can be dragged, resized, and positioned. Uses `interactjs` for drag/drop/resize.

### Timeline Component

Multi-track timeline below the canvas. Each element type (text, image, video, form) gets its own layer row. Playhead scrubs through time. Zoom slider controls view scale.

### Form Elements

When user clicks "Add Form" in toolbar, the retarget/form popcorn plugin creates an interactive lead generation form overlay on the canvas. The form settings panel (Styles/Fields/Integrations tabs) appears in a modal for configuration.

### Connect Templates

When user clicks "Templates" in toolbar, the template gallery modal shows pre-built form configurations. Clicking a template imports its settings into the current project.

### Lottie Animations

When user clicks "Add Animation" in toolbar, they can pick from built-in Lottie JSON animations or upload custom ones. The animation renders on the canvas and plays during video playback.

### State Flow

```
User Action → Store Update → UI Re-render
     ↓              ↓              ↓
  Toolbar click  projectStore   Canvas re-renders
  Drag element   .elements[]   Timeline updates
  Play button    .time          Playhead moves
  Form submit    webhook URL    Data sent externally
```
